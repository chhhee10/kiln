## Default Permission

Push registration, notification deep links and speech recognition for the Kiln Android app.

#### This default permission set includes the following:

- `allow-register-push`
- `allow-unregister-push`
- `allow-take-pending-link`
- `allow-start-listening`
- `allow-stop-listening`
- `allow-register-listener`
- `allow-remove-listener`
